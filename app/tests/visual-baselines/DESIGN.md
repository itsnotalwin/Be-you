# BE YOU visual snapshot evidence

The design target is the user-approved 23-view BE YOU editorial interface: dark charcoal and ivory, restrained serif typography, authentic approved manga artwork, unobstructed content, one reactive mood selector, 4-tab mobile navigation and desktop sidebar. These PNGs are **real browser captures**, not the approved conceptual mockup boards. They document actual implementation appearance and need separate review before being accepted as locked snapshots.

**Capture source:** actual running `app/` at `?screen=today` and the routes/states in `../visual.spec.mjs`.
**Canonical capture:** `SCREENSHOT.png`, Chromium 390×844, UTC, frozen at 2026-10-17 12:00, generated 2026-10-17.
**Other viewports:** Chromium 320×700 and 1280×800; WebKit 393×852. Device pixel ratio 1, fixed English locale, fonts/images settled, reduced motion.
**States:** 21 direct routes plus populated/view journal, five emotions each with portrait and scrolled controls.

These images are **candidate baselines**, pending review in the pull request. Pixel comparisons measure unapproved change, not compliance with artwork, accessibility or physical-device behaviour.
