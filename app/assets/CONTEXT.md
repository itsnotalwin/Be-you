# App Assets

**Purpose:** Art, brand and icons for the sole BE YOU PWA.

**Key locations:** `approved/volume-03/` is the active art set and origin/provenance index. `approved/volume-01/` and `approved/volume-02/` are older assets kept for historical review. `icons/` contains PWA icons; `brand/` contains foundational wordmark/botanical assets.

**Connections:** `../ui-primitives.js` resolves all active artwork, and `../sw.js` caches it offline.

**Change & verify:** Image IDs and license notes must remain traceable; optimize without changing user-approved theme. Avoid reactivating archival illustrations.
