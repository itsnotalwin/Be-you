# BE YOU — 23-screen approved implementation

The reference baseline was approved on 2026-10-16: [`../references/approved/mockups-2026-10-15/`](../references/approved/mockups-2026-10-15/README.md). All 23 mockup views are implemented as real screens or data-dependent states inside `functional.js`, not baked-in screenshots. Active assets are exclusively eight pre-approved Volume 01/02 manga illustrations. The actual interface uses a near-black / ivory editorial design with serif headlines, generous margins, full-width art panels, soft pill CTAs, and four mobile tabs: Today, Journal, Grow and You. `app.css` remains the original foundation; the final shared overrides live in `responsive.css`. Desktop layout retains its original navigation; scrollable layouts remain real.

**Behavior:** mood selection/details/save, journal empty/list/new/view/edit/search/delete, four guided journeys, progress saving, insights, affirmations, breathing, settings/export/import, onboarding and PWA install/offline. Browser localStorage is unencrypted and not synchronized.

**Screenshot evidence:** Real local Chromium captures of the running implementation: `SCREENSHOT.png` (Today, 390×844), `SCREENSHOT-MOBILE-JOURNAL.png`, `SCREENSHOT-MOBILE-GROW.png`, `SCREENSHOT-MOBILE-MOOD.png` (same viewport), and `SCREENSHOT-DESKTOP.png` (representative 1280×800 desktop renderer). Captured 2026-10-16 with synthetic local test data where relevant, never generated as a mockup. These do not by themselves prove a live production capture; production layout and native devices still need independent checks.

**Limits:** Browser simulation is not a replacement for iPhone Safari, Android, PWA update or accessibility/security/privacy audits. Historical README gallery items predate this baseline and remain marked as such.

**Stabilization (2026-10-16):** The 23-screen CSS footer override inadvertently re-enabled the phone tab bar at desktop widths (1024px and above); a final breakpoint rule restores the desktop sidebar-only layout. The service worker previously served code and styles cache-first, which could leave a user's browser on stale mixed releases. Core assets now use network-first with offline fallback, and cache cleanup is limited to BE YOU rather than other GitHub Pages PWAs. Worker takeover announces reload without interrupting an in-progress writing draft. **Evidence still needed:** new genuine 390px phone and 1280px desktop captures and a live browser/PWA update check after this stabilization; the earlier screenshots document the pre-fix UI, not this patch.
