# BE YOU — Locked Art Direction (v1)

## Core approach

**Minimal monochrome manga editorial illustration**, matching the *restrained* design in the original app reference. It should look like a calm premium mobile editorial, **not** a densely shaded anime artbook or painterly fantasy poster.

### Required characteristics

- Warm ivory backgrounds; inky near-black foregrounds; charcoal app UI.
- Graphic black hair masses and clothing silhouettes.
- Delicate, fine facial contours: expressive eyes, subtle eyelashes, restrained lips.
- Minimal or no gradients, no photorealistic shading, limited cross-hatching.
- Strong negative space; simple high-contrast compositions, intentional cropping.
- Consistent short, loose, dark bob hairstyle on the lead protagonist; black high-neck clothing in baseline portraits.
- Koi fish, sakura and petals as **occasional accents**, not mandatory busy overlays.
- Quiet, introspective mood with expression variants: neutral, calm, happy, sad, anxious, hopeful.

### UI approach

- Deep charcoal background (`#1A1D22`, direction only), secondary panels around `#282D33`.
- Warm ivory artwork field around `#E5E2DD`; nearly-black ink around `#191C20`.
- Large high-contrast editorial serif titles + crisp restrained sans-serif UI text.
- Keep illustration separate from the UI text: the app should render headings and controls as real text, not text baked into art.
- Prefer simple cards, generous margins, and bottom navigation consistent with the source reference.

### Avoid

- Dense fantasy backgrounds, gradients, shiny effects, 3D, anime neon, chibi styles.
- Different faces or hairstyles for the same recurring character between screens.
- Mixing AI illustration styles across assets.
- Copying an existing character, screenshot, or artist's original copyrighted work as production assets.

### Review checklist for each new original artwork

1. Is the protagonist visibly consistent with `references/approved/01-character-sheet.png`?
2. Does the frame use the same graphic black fill and fine facial linework?
3. Is negative space preserved for interface text and cropping?
4. Is the composition useful at real mobile sizes (not just in a collage)?
5. Are eyes, hands, hairline, outfit, koi anatomy and accessory details coherent?
6. Is it a **standalone** image with sufficient source resolution?
7. Are usage rights and asset provenance documented?

### Approval / versioning

These three boards are **approved visual references**, not yet approved final production assets. New versions should have distinct filenames and a change note rather than silently replacing the baseline.
