# From approved references to production illustrations

1. **Character lock:** select the front and ¾ views from the character sheet, then generate a separate, large clean protagonist portrait with that exact visual direction.
2. **Expression library:** make six standalone emotion portraits; revise until haircut, eye proportions, clothing, and ink weight agree.
3. **App compositions:** make splash, onboarding, 4 journey cards, and a journey cover as separate outputs — not screenshots or crops of this repo's sheets.
4. **Review in-app:** place optimised copies in actual BE YOU UI and compare at phone sizes before declaring artwork final.
5. **Export:** retain masters, plus responsive WebP/AVIF variants. Use PNG transparency when required. Name by stable semantic purpose and version.
6. **Rights & provenance:** record origin and permissions for all source images. AI-generated boards are creative references; the user-supplied original may have separate ownership rights.

For app teams: this repository is **design input**. The previous working BE YOU PWA source is a separate deliverable and is not contained here.
