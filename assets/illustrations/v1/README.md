# BE YOU — Illustration production, Volume 01

## Approved visual identity
This directory contains **independent production assets**, not crops from concept boards. Minimal flat editorial manga: bold near-black fills, delicate linework, ivory backgrounds, minimal tonal shading, contemplative expressions, sparing symbolic koi and botanical motifs.

### Tokens
- Ink `#191C20`
- Ivory `#E5E2DD`
- App background `#1A1D22`

### Current contents
- `decorative/twin-koi.svg`: original scalable transparent vector illustration.
- `decorative/blossom-branch.svg`: original scalable transparent vector illustration.

### Planned standalone imagery
- `characters/protagonist-master.png`: independent splash-character hero with koi, **pending final review**
- `characters/expressions/`: neutral, calm, happy, sad, anxious, hopeful
- `journeys/`: travel-journal, unsent-letter, rethinking-loneliness, letting-go

**Asset acceptance criteria:** One illustration per file; no embedded logos, labels, frames or UI; preserve original composition and proportions; visually consistent main character; source masters and optimized app variants distinguished; validate mobile cropping and transparency before use.

### Status
Approved boards live under `references/approved/`. They are creative direction only. Do not treat enlarged crops of concept boards as high-resolution originals.
