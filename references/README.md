# Approved BE YOU visual references

**The approved art direction is minimal editorial manga:** strong ink silhouettes, warm ivory, expressive but restrained linework, quiet spacious layouts, and selective koi and floral motifs.

1. [Main character and expressions](approved/01-character-sheet.png) — protagonist reference.
2. [Illustration library](approved/02-illustration-library.png) — visual vocabulary and image roles.
3. [Updated app screens](approved/03-updated-app-screens.png) — interface aesthetic and composition.
4. [Original visual inspiration](inspiration/00-original-visual-reference.jpg) — direction only, not an asset for reuse.

These boards are **references, not production assets**. Eight approved standalone artwork files are in [`../app/assets/approved/`](../app/assets/approved/) and are already wired into the application.

Avoid adding alternative art treatments here without approval. Keep the runtime application assets in `app/` and avoid copying them into a second source folder.
