## Rules

- One real app in `app/`. Reference mockups live here, **not** rendered as in-app screenshots.
- Use only the eight existing approved manga illustrations (Volume 01 and 02). No new faces or experimental variants.
- Quiet dark charcoal, ivory surfaces, large image-led compositions, generous margins, restrained serif headlines, soft pill controls.
- The bottom mobile navigation shows Today / Journal / Grow / You. Desktop retains a persistent navigation workspace.
- Both journal empty and populated states are real and data-dependent, not hardcoded demonstration content.
- Real validation screenshots are stored under `app/SCREENSHOT*.png` and must be refreshed after future visual code changes.
